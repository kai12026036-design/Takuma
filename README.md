# Takuma
My name is Takuma.

## Web app

ブラウザ版は `index.html` を開いて利用できます。ローカルサーバーを使う場合は、リポジトリのルートで次を実行してください。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

ログイン情報:

- 先生: `sensei` / `1234`
- 生徒: `student` / `5678`

作成中はユーザー名とパスワードを空欄のまま送信すると、選択した役割で確認できます。パスワードを入力した通常ログインも引き続き利用できます。

先生は時間割セルをクリックして編集できます。編集内容はブラウザに自動保存され、`timetable.txt` としてダウンロードもできます。

持ち物ビューでは、先生が一覧から持ち物名と関連教科を選び、基準写真を撮影して登録できます。生徒側では当日の時間割に関連する持ち物だけが自動表示され、「写真で忘れ物チェック」で撮影するだけで、先生の基準写真と最も一致する持ち物を自動判定します。持ち物データと写真はこのブラウザの `localStorage` に保存されます。照合は外部サービスを使わない簡易画像特徴比較なので、表示された一致度を目視でも確認してください。
